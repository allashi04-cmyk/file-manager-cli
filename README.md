# CLI File System Manager

Консольная утилита для управления файловой системой. Позволяет копировать, удалять, искать, анализировать размеры и массово переименовывать файлы с соблюдением рекурсивной обработки и базового логирования.

##  Установка

Проект работает исключительно на стандартной библиотеке Python. Внешние зависимости не требуются.

```bash
# 1. Клонируйте репозиторий
git clone <url-вашего-репозитория>
cd file-manager-cli

# 2. Убедитесь, что установлен Python 3.8+
python --version

file-manager-cli/
├── cli.py                  # Точка входа: парсинг аргументов (argparse), маршрутизация команд
├── filesystem/             # Бизнес-логика работы с файловой системой
│   ├── __init__.py
│   ├── copy.py             # Копирование файлов
│   ├── delete.py           # Удаление файлов и папок
│   ├── count.py            # Рекурсивный подсчёт файлов
│   ├── search.py           # Поиск по регулярным выражениям
│   ├── add_date.py         # Добавление даты создания в имя файла
│   └── analyse.py          # Анализ размеров и вывод дерева
├── tests/                  # Юнит-тесты (unittest)
│   ├── __init__.py
│   └── test_filesystem/
│       ├── test_copy.py
│       ├── test_delete.py
│       ├── test_count.py
│       ├── test_search.py
│       ├── test_add_date.py
│       └── test_analyse.py
├── .gitignore              # Исключение кэшей, venv, IDE-файлов
├── requirements.txt        # Зависимости (пусто, используется stdlib)
└── README.md               # Документация проекта
